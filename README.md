# Practicas-Domotica
Guías y prácticas de domótica e IoT: evolución desde sistemas cableados (KNX, X10) hasta tecnologías inalámbricas con ESP32, Arduino Cloud, Blynk, Amazon Alexa y Home Assistant. Incluye análisis de dispositivos comerciales y marcas globales/Ecuador (Sonoff, Tuya, Lutron) para el control inteligente del hogar.
